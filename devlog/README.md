# Devlog

A running diary of the build: one file per working day, named `YYYY-MM-DD.md`.
Screenshots go in `images/`, named `YYYY-MM-DD_<what>.png`.

Each entry covers:
- **Done**: what got built or changed, with screenshots
- **Decisions**: choices made and why
- **Problems**: what broke and how it was fixed (or that it wasn't)
- **Next**: what comes next
